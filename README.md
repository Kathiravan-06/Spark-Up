# 🌍 Disaster Preparedness and Response Education System

## 📌 About The Project

The **Disaster Preparedness and Response Education System** is an educational web application designed to create disaster awareness among school and college students.

The platform provides interactive learning modules, quizzes, educational games, and safety guidelines to help students understand different types of natural disasters and learn how to respond effectively during emergency situations.

The main objective is to make disaster education more engaging, accessible, and practical through interactive digital learning.

## 🎯 Objectives

- Create awareness about natural disasters and their impacts.
- Educate students about disaster preparedness and emergency response.
- Provide interactive learning experiences through quizzes and games.
- Teach essential Do's and Don'ts during disaster situations.
- Track individual student learning progress and achievements.
- Encourage students to develop safety awareness and emergency response skills.

## ✨ Key Features

### 📚 1. Interactive Learning Modules

- Educational content about different natural disasters.
- Step-by-step safety instructions.
- Disaster-specific Do's and Don'ts.
- Easy-to-understand learning materials.

### 🧠 2. Disaster Awareness Quiz

- Interactive multiple-choice questions.
- Disaster-specific quizzes.
- Instant feedback and score calculation.
- Helps evaluate students' understanding.

### 🎮 3. Disaster Survival Mini-Games

- Interactive educational games.
- Disaster survival challenges.
- Scenario-based learning.
- Helps students understand emergency decision-making.

### 📖 4. Knowledge Base

- Centralized disaster safety information.
- Searchable educational resources.
- Emergency preparedness guidelines.
- Safety posters and awareness materials.

### 📊 5. Student Progress Tracking

- Tracks completed learning modules.
- Monitors quiz scores and game completion.
- Displays individual learning progress.
- Achievement badges and rewards.
- Encourages continuous learning.

### 🗺️ 6. Map & Emergency Assistance

- Interactive map interface.
- Location-based assistance features.
- Emergency awareness and safety support.

## 🌪️ Disaster Learning Modules

The application covers the following disaster categories:

| Module               | Learning Focus                               |
| -------------------- | -------------------------------------------- |
| 🌎 Earthquake        | Drop, Cover and Hold On                      |
| 🌊 Flood             | Moving to higher ground and flood safety     |
| 🌊 Tsunami           | Moving inland and reaching higher ground     |
| 🔥 Fire Accident     | Stop, Drop and Roll                          |
| 🌪️ Cyclone          | Before, during and after cyclone safety      |
| ⛰️ Landslide         | Warning signs and evacuation procedures      |
| 🌍 General Disasters | Disaster preparedness and emergency response |

Frontend Development: HTML5, CSS3, JavaScript

Storage & Data Management: LocalStorage, SessionStorage

Tools & Platforms: Git, GitHub, VS Code

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/your-username/Disaster-Preparedness-System.git
```

**2. Navigate to the project folder**

```bash
cd Disaster-Preparedness-System
```

**3. Open the project**

Open `index.html` in your browser or use the VS Code Live Server extension.

**4. Explore the application**

Register or log in and explore the learning modules, quizzes, games, knowledge base, and student dashboard.
